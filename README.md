## 🌐 Overview

A high-performance, dark-mode portfolio engineered with Next.js 14, TypeScript, Tailwind CSS, and Vanilla CSS. Built to showcase verifiable production systems, protocol architecture, interactive prototypes, and transparent mini case studies without vanity metrics.

### Key Architecture Features
- **Cinematic Kinetic Entrance (`RastaDev`)**: Autonomous coordinate lock and kinetic typography entrance sequence with zero-lag ESC skip.
- **Interactive System Map**: Floating SVG telemetry map connecting Users, Frontend Systems, Relayers, and Smart Contract Protocols.
- **Transparent Mini Case Studies**: 4-part structured breakdowns (*What it is*, *Why it matters*, *What I built*, *Where to see it*) for all flagship products.
- **Simulation Transparency Badging**: Explicit disclaimers on interactive prototype sandboxes (*"Interactive concept preview • Simulated demo data"*).
- **Expandable Architecture Deep Dives**: In-depth architectural case studies for **TipWall** and **Staxiq**.
- **Interactive Process Pipeline**: 4-phase visual engineering methodology stepper (*Discover → Design → Build → Ship*).
- **Curated Lab Archive**: Multi-category filter (*DeFi*, *Payments*, *Developer tools*, *Automation*, *Hackathons*) with collapsible drawer.
- **Mobile-First Touch Architecture**: Generous tap targets (48px+), zero horizontal overflow, and reduced-motion accessibility support.

## 💻 Getting Started Locally

### Prerequisites
- Node.js `>= 18.17.0`
- npm, pnpm, or yarn

### Installation
```bash
# Clone the repository
git clone https://github.com/natureloved/adejoke-portfolio.git

# Navigate to the project directory
cd adejoke-portfolio

# Install dependencies
npm install

# Start the local development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) (or the port specified in terminal) in your browser.
